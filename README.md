# UAS-PW1

Ujian Akhir Semester Pemrograman Web 1 — S1 Sistem Informasi, Universitas Pamulang.

## Isi repo

- Website UAS: `index.html`, `home.html`, `profil.html`, `transaksi.html`, `pendaftaran.html`, `kami.html`, `kontak.html`, plus `styles.css` dan `script.js`
- `SOAL UAS WEB.docx` — soal UAS Pemrograman Web 1
- `Saran_Lengkap_Presentasi_QuickSell.pdf` — saran lengkap presentasi QuickSell

## Cara jalanin

Buka `index.html` langsung di browser, atau serve folder ini dengan static server apa aja, misal:

```bash
python3 -m http.server
```

Terus buka `http://localhost:8000`.
